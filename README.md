نسخه اول سایت کتابخانه شخصی ArslanM_86br.

## امکانات
- فیلم، سریال، انیمه، انیمیشن و کتاب
- تعداد خودکار هر دسته
- جستجو بر اساس اسم و ژانر
- پوستر/جلد قابل آپلود
- پنل مدیر برای افزودن و حذف

## اجرا
نیازمندی: Node.js نسخه 20 یا بالاتر.

```bash
npm install
npm start
```

بعد مرورگر را باز کن:
http://localhost:3000

## ورود مدیر
برای تست محلی، رمز پیش‌فرض:
ArslanM_86br

برای محیط واقعی حتماً این متغیرها را تنظیم کن:
- ADMIN_PASSWORD
- SESSION_SECRET

مثال:

Linux/macOS:
```bash
ADMIN_PASSWORD="یک-رمز-قوی" SESSION_SECRET="یک-رشته-طولانی-تصادفی" npm start
```

Windows PowerShell:
```powershell
$env:ADMIN_PASSWORD="یک-رمز-قوی"
$env:SESSION_SECRET="یک-رشته-طولانی-تصادفی"
npm start
```

## نکته انتشار
این نسخه برای شروع و تست کامل محلی ساخته شده است. برای انتشار دائمی، بهتر است در مرحله استقرار از دیتابیس و فضای فایل دائمی (persistent storage) استفاده کنیم تا SQLite و پوسترها با ری‌دیپلوی پاک نشوند.


## انتشار پیشنهادی
برای نسخه عمومی، سرور Node.js باید روی یک سرویس دارای اجرای دائمی و فضای ذخیره‌سازی پایدار اجرا شود. دلیلش این است که این نسخه از SQLite و پوشه `uploads` استفاده می‌کند. در استقرار واقعی، برای `data/` و `uploads/` باید persistent disk/storage داشته باشی تا با هر redeploy اطلاعات پاک نشوند.

قبل از عمومی کردن سایت:
1. `ADMIN_PASSWORD` را با یک رمز قوی عوض کن.
2. `SESSION_SECRET` را با یک مقدار تصادفی طولانی عوض کن.
3. برای HTTPS از دامنه و SSL سرویس میزبان استفاده کن.
4. برای بکاپ، فایل دیتابیس و پوشه uploads را دوره‌ای ذخیره کن.
